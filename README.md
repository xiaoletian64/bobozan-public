# 波波赞

三拍节奏掌心对决游戏，包含街机闯关、无限挑战、本机排行榜与蓝牙双人实验功能。

这是经过隐私清理的公开源码快照。原始私有开发历史、内部交接、个人签名配置和构建附件不包含在内。公开源码不等于已通过全部真机验收；蓝牙跨设备互联仍待验证。

## 使用

使用 Godot 4.4.1 打开 project.godot。Android 与 iOS 原生桥接、测试与构建脚本保留在 native/、tests/、tools/。发布前配置自己的 Apple 团队、包名和签名。OTA 地址使用 updates.example.invalid 占位，需替换为自己的更新服务，公开源码不会访问原私人服务器。
