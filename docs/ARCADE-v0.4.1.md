# 街机连续闯关 v0.4.1

在 v0.4.0 的三擂三局两胜上增加完整的街机路线。借鉴连续挑战、续关与通关收尾结构，使用本项目原创角色、路线图与动效。

## 完整流程

首页「街机闯关」→ 三对手路线 → 开始挑战 → VS → 三局两胜 → 晋级路线 → 下一位登场 → 最终擂主 → 通关战绩。

- 路线显示三位对手，已击败盖章，当前对手高亮，擂主始终可见。头像是原生矢量绘制的小熊猫，不额外加载图片。
- 小局结算停留 3.8 秒用于看原因与最近交锋，然后自动开始下一小局；整擂获胜停留 3.2 秒，接 2.2 秒下一位介绍及 1.6 秒 VS 演出。
- 转场可立即跳过或暂停；切到后台后保持暂停，回来需手动继续。回首页取消所有自动推进。
- 输整擂不会自动续关。点「续关」才增加次数、重置当前擂的比分与节奏；整轮总交锋、小局胜负、已击败对手和翻盘统计保留。重复点击不会重复加次数。
- 三位对手有登场台词；墨尾增加抱臂姿态、紫色擂台与登场光圈，最终获胜有「终擂 · 决胜」与金色光圈。
- 通关画面展示各擂比分、小局胜负、总交锋、翻盘与续关次数。全胜、无续关、普通通关分别显示对应标题。
- 本轮数据保存在运行期间；回首页或结束应用会结束该轮。旧成就、签到、装备和音色的持久化逻辑不变。双人模式保留原规则与结算，不自动晋级。

## 验证

11 组脚本通过：arcade、arena、flow、network_flow、finisher、tempo、skins、voice、achievements、rules、network。新增 arcade 覆盖从开场到通关的完整链路、自动与跳过推进、后台暂停、败北等待、续关去重、擂主登场、战绩和回首页取消。

实际 Godot 渲染检查：开场路线、VS、晋级、最终擂主、通关战绩与首页。`docs/arcade-motion.mp4` 为引擎录制的 28 秒编排演示，展示连续转场和最终决胜，并非完整真人对局录像。

Android 0.4.1 / versionCode 9，包名继续为 `com.prototype.bobozan`。本轮未操作已连接的实体手机，也未占用正在运行其他项目的模拟器；Android 真机手感与 BLE 双机互联仍需实测。
