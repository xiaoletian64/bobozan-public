# 波波攒 v0.2 · 人物、节奏与交锋成就

针对本轮反馈，把“看得清、喊得顺、打得有劲、长局有纪念”落到可玩原型。

## 1. 人物：掌心少年
从球体拼接基础人形升级为轻武侠潮玩角色：分层发束、发带飘动、眉眼与瞳孔高光、眨眼、鼻耳嘴、交领武道服、腰带结、护腕与缠腿、鞋底和手指。双方保留青绿/暖橙辨识色。肩和肘分别控制，准备、蓄力、推掌、格挡之间连续过渡。

仍然是程序化三维原型，不冒充专业雕刻或 Blender 精细绑定成品。后续可按同一动作接口替换美术模型。

## 2. 口令与末拍
用户已澄清：只去掉“儿”，保持“波波攒、波波防”的原有三拍口令。当前准备拍读“波”，末拍读动作名，不额外读“出招”；游戏名称仍为“波波攒”（攒能量）。不将地方口令差异描述成唯一标准。

| 时间 | 行为 |
|---|---|
| 0.00 秒 | 第一声“波”，准备动作，电脑先确定暗选 |
| 0.75 秒 | 第二声“波”，玩家仍能改招 |
| 1.80 秒 | 选择光条走满，锁定、喊招、双方出手 |
| 2.35 秒 | 飞行约 0.55 秒后到达，触发格挡/抵消/命中 |
| 2.60 秒 | 无人被击败则进入下一轮 |

相较旧版 1.40 秒锁定，增加 0.40 秒选择余量。削去语音文件开头空白，不用抢点准确率决定胜负。静音保留口令文字、进度光条、三拍点阵和动作。

## 3. 回合效果与终结
- 新回合：脚下扩散准备光环。
- 攒：能量核心与半透明外晕，脚下聚气环。
- 格挡：防护罩、接触点冲击环与碎光；对波显示抵消。
- 有效命中：飞行结束后才触发，暖色斜向光痕 + 破防/一击文字 + 放大冲击环和碎光。
- 命中瞬间定格 140 毫秒，随后镜头小幅震动与推近，受击倒地、胜者庆祝，再显示重开按钮。全段约 1.65 秒。
- 不改全局时间倍率；后台时战斗/终结时钟均暂停，恢复三秒倒数。

这是非血腥的“终结演出”，不改变一次命中输赢的规则。强化波/防成本仍沿用 v0.1 暂定值，需要后续确认。

## 4. 交锋成就

“连续对战”暂解释为**同一局交锋的已完成回合数**，不是累计局数，也不是连胜。决胜回合计入，下一局归零；个人最长纪录和已解锁徽章留在本机。

| 成就 | 条件 | 表现 |
|---|---|---|
| 渐入佳境 | 单局完成 10 回合 | 金色非模态提示 |
| 见招拆招 | 单局完成 20 回合 | 徽章 + 本地记录 |
| 巅峰拉锯 | 单局完成 30 回合 | 徽章 + 本地记录 |
| 初露锋芒 | 首次获胜 | 首胜纪念 |

对战显示当前回合进度；新成就逐条提示约 3.2 秒，不阻断下一回合；首页“交锋成就”可查看。重复达成不重复解锁。徽章不加属性，不引入账号/养成/付费。试玩录像使用隔离存档，不给真实玩家账号写入假成就。

## 验证
规则组合与 AI 测试继续保留。新增 1.40 秒仍可选择、1.80 秒锁定的边界测试；成就阈值、重复达成、跨局不累计、本地重读测试；终结延迟、定格、后台暂停恢复测试。预览是实际引擎录制的效果演示，不是实战成绩证明。
