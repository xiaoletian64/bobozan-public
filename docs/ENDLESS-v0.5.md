# 无限闯关与本机排行榜 v0.5.0

首页独立提供「街机闯关」「无限闯关」「本机排行榜」。原三擂街机、蓝牙双人、皮肤签到和双音色继续保留。

## 无限模式

对手按赤练、青岚、墨尾轮换，关数持续递增，第三关后不通关。每关三局两胜，每小局能量重新开始；整关失败即结束本轮，无限模式不续关。赢下整关沿用自动晋级、VS、暂停和跳过；每三关出现墨尾守关者演出。

基础速度逐关提升，第七关起达到已有速度上限（0.34 秒一拍），同关仍保留小局间加速。AI 对历史招式的重视和选择稳定度在前十三关逐步提高，然后封顶。只使用公开能量与历史动作，不读取当前暗选，不增加电脑能量或改规则。无限关数不等于无限加速。

对局历史最多保留 24 条，已击败对手详情最多保留最近 3 条；总关数、总胜负和交锋数单独累加。避免长时间游玩时列表无界增长。

## 排行榜

仅本机真实成绩，没有虚构玩家或全球名次。每轮独立 ID，每个小局结算更新同一条；回首页也结算已获成绩。保存前 20 条，优先通关数，其次败局更少、交锋更少、记录时间更早。败北页显示本轮名次和止步关数；榜单显示日期、关数、胜负、交锋与记录状态，超过可见区域可滚动。

成绩文件 `user://endless_board_v1.json`，使用临时文件替换并保留上一份备份。坏记录过滤、主文件损坏时回退备份；保存失败保留内存成绩并显示提示，可在榜单页重试保存。卸载会清除数据。

「阶段记录」是上一小局结束时的检查点成绩，不是可继续的关卡存档。结束应用后，本轮进度不恢复；已写入的成绩仍保留。跨设备、好友或全球排行需要账号/服务端与成绩校验，本版未接入。
