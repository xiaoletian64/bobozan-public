# 基础角色、皮肤与三日签到

2026-09-27 实现记录。

更新：0.3.3 已按 C 方向替换为小熊猫武者，外观名改为「竹影 · 小熊猫」/「赤焰 · 行者」，内部编号和三日签到不变。下文早期兜帽造型为历史记录，当前模型见 RED-PANDA.md。

## 当前体验

首页「角色与签到」进入衣柜。角色采用同一套关节和动作接口，重做为大头兜帽、简化眉眼、训练外套、拳套与厚底鞋的 Q 版形象。

- **云白 · 见习**：默认拥有，奶白外套与墨色护具。
- **赤焰 · 小虎**：累计签到三天解锁，暖橙兜帽、虎耳、额纹与赤色围巾。配件与材质叠加在同一基础身形上。
- 未拥有的皮肤可试穿，不能装备。退出试穿恢复已装备外观，预览不会修改存档。
- 皮肤不影响能量、命中、技能与胜负。双方识别色仍用于胸章、能量和斩杀效果。
- 蓝牙握手附带皮肤编号，对方按编号显示；未知或缺失编号降级到基础皮肤，不参与规则摘要。收到对方的皮肤编号不授予本地所有权。

## 签到约定

手动点击「今日签到」。按设备本地日历日期每天最多一次，累计三天，不要求连续，中断不清零。第三天自动解锁，玩家再选择装备；第四天及以后继续记录，不重复授予奖励。

保存路径为 `user://cosmetics_v1.json`，版本 1，包含 `days` 与 `equipped`。采用临时文件写入后重命名，保存失败回滚本次操作。读取时检查日期、去重、检查已装备皮肤是否拥有。检测到日期早于最近签到时不计入，提示检查时间。

这是离线本机签到：改设备日期或编辑存档不具备服务器级防护，卸载/清除数据会失去记录。没有账号、跨设备同步或真实服务器授权。

## 代码边界

- `scripts/fighter.gd`：基础身形、共用动画、材质槽与配件；`apply_skin(id)` 只改变外观。
- `scripts/cosmetics/skin_catalog.gd`：皮肤编号、名称、调色板及获取来源；新增皮肤从这里登记。
- `scripts/cosmetics/skin_profile.gd`：离线签到、所有权判断、装备持久化。
- `scripts/cosmetics/wardrobe.gd`：展示与操作信号，不自行授予奖励。
- `scripts/cosmetics/activation_provider.gd`：未来服务器授权提供方接口。当前 `is_available()` 返回 false，`sync_entitlements()` 返回 `not_configured`；没有伪造成功或任意 JSON 导入激活的入口。

4. Profile 的所有权查询接入经过验证的权益仓库，处理撤回、过期、账号切换和装备回退；衣柜与角色渲染继续使用现有编号。

6. 新皮肤模型或资源需随版本/受控资源包发布；首期服务器只下发已内置皮肤的授权编号，不下载执行脚本。
