# 小熊猫武者 · Android 0.3.3

2026-09-27，按用户选定的 C 方向制作游戏内角色。概念图作为造型参考；实际游戏使用移动端风格化网格，不将概念图作为模型或实机截图。

## 模型与动作

新增 `scripts/models/red_panda.gd`：曲面头部、奶白面颊、深色眼周、口鼻、立耳、交领武道服、护腕与爪掌，以及独立摆动的连续环纹尾巴。服装和肢体使用有轮廓变化的曲面，头部及尾巴使用顶点颜色；共用静态网格并建立索引，避免每个角色重复构造同一资源。

`fighter.gd` 保留原有 `act()` 动作接口与肩肘、腿部关节。接入准备、攒、波、防、强化、受击倒地和胜利；普通动作跟随渐进节奏，决胜斩杀保持常速。修正倒地姿态高度，并补偿尾巴旋转。不是毛发模拟、专业绑定或与概念图等精度的模型。

## 皮肤兼容

- 基础款：**竹影 · 小熊猫**，青竹色武道服。
- 累计三日奖励：**赤焰 · 行者**，赤色武道服、金色饰边、披巾与腰扣。

保留内部 `cloud` / `tiger` 皮肤编号，不重置旧版三日签到记录或已装备状态。原有小虎奖励自动以行者外观显示。新外观不改变任何战斗规则，服务器激活仍为预留接口。

`test_skins.gd`、`test_finisher.gd`、`test_tempo.gd`、`test_network_flow.gd` 通过。Godot 桌面渲染检查基础款、奖励款、左右出招、命中和倒地。截图包括 `panda-cloud.png`、`panda-reward.png`、`panda-character.png` 及 `panda-fall-0.png`。
