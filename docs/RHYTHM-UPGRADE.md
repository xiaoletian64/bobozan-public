# 渐进三拍与音效调整 · 0.3.2

2026-09-27。

## 节奏

三拍改为等间距；第 1–5 回合每拍 0.90 秒，第 6 回合起线性加速，第 25 回合达到每拍 0.34 秒并保持。第 10 / 15 / 20 回合分别为 0.76 / 0.62 / 0.48 秒。每轮三拍，第三拍锁定并出招；普通命中演出按节奏缩放，决胜斩杀保持原有 1.65 秒演出与 140 毫秒定格。

`tempo.gd` 集中配置曲线，`beat_clock.gd` 按轮累计实际时刻，暂停和重开不沿用上一局速度。界面显示当前节奏倍数。

## 声音

移除覆盖在两声「波」与出招语音上的正弦电子音。保留原有授权来源的中文合成音色，生成 1.0–2.0 倍的保音高压缩版本，并做短淡入淡出和音量降低。没有更换真人配音，也没有宣称听感已获用户认可。

强化动作语音简化为「波」「防」，画面仍明确区分强化动作，避免高速时三字口令挤占下一拍。命中使用短促低音量滤波噪声，不再播放长电子蜂鸣。

`tools/prepare_rhythm_audio.py` 可复现音频处理；音频来源和文件校验见 `release/rhythm-audio-provenance.json`。`docs/rhythm-preview.wav` 是第 1、10、15、25 回合各三轮的试听拼接，非实战录音。

## 双人

双方按相同回合号使用同一曲线，旧版规则标识会拒绝连接。口令仅由房主设备发声，减少两台设备回声；双方仍有文字节拍。保留承诺/公开/校验后共同出招，削减原有固定等待，下一轮提前约定。

网络出招仍需通信缓冲，不能保证真实蓝牙环境下三拍无间隙。慢链路使用更大的拍长下限，不以跳过验证换速度。当前验证为 30/300 毫秒单程延迟、317 毫秒时钟差的模拟，不是无线实机验收。

## 人物

后续 0.3.3 已按用户选择的 C 方向接入小熊猫模型，见 RED-PANDA.md。以下为 0.3.2 当时记录：本版暂保留现有模型、皮肤与签到，不将概念图当作已导入游戏的模型。已提供 A 火柴人武者 / B 动漫少年 / C 小熊猫武者方向图，人物风格等待用户选择后再制作替换。
