# 波波攒 PRD v0.1

> 2026-09-25 更新：人物、口令、节奏和本地成就已按 [v0.2 设计](DESIGN-v0.2.md) 调整；该文档中时间参数以 v0.2 为准。

目标：还原两个人对坐喊“波、波、攒/波/防”的短局心理博弈。首版离线对电脑，无账号、匹配、养成或付费。Android/iOS 共用 Godot 4.4.1 GDScript 工程；Compatibility 渲染。横屏，程序化真实三维角色为原型美术，不代表 Blender 精细成品。

## 节奏与输入
每拍 0.7 秒，前两拍准备，可反复改选，第三拍锁定并同时结算。全回合 2.1 秒，连续不停顿。这是待试玩验证方案，不做音游准确度判定。未选默认普通防。静音仍显示节拍。切后台暂停，回前台三秒倒数恢复。

## 已确认规则
攒获得能量；普通波至少需要一个攒；普通防免费挡普通波；强化防消耗能量。AI只能使用历史和公开能量，不能读取当轮暗选。

## 原型暂定规则（需要用户确认）
能量上限 5；攒 +1，波 -1，强化波 -3，强化防 -1。普通波打攒命中、波对波抵消；强化波击穿普通防和普通波，强化防挡全部攻击；同等级波抵消，各付成本。一次有效命中即输。强化攻击与强化防原始语音存在矛盾，以上仅为可配置试玩值，不是已确定需求。强化波避免免费防成为永久无敌策略。能量达到上限仍允许攒（无额外收益）。

## 页面与动作
首页：开始、玩法、音效、单人动作展台。对战：双方三维角色、公开能量、节拍、选中/不可用动作。结算：再来、首页。角色包括准备、攒、波、防、强化、受击倒地和胜利动作；口令、动作、特效按拍同步。

## 架构
rules.gd 纯结算；opponent.gd 只接收公开状态；beat_clock.gd 节拍时钟；fighter.gd 三维表现；main.gd 界面与调度。未来双人通过输入接口接入。蓝牙双人为用户明确要求的后续必做功能：iPhone 与 Android 必须互通，同时覆盖两种同平台组合。采用共同 BLE/GATT 协议路线，当前尚未实现、未真机验证；详见 [蓝牙双人设计](BLUETOOTH-DUEL.md)。需求已确定与功能已验证须分别表述。

## 验收与限制
执行全动作/能量组合规则测试、AI合法性、节拍与后台恢复检查；桌面实际渲染验收。Android 导出/设备安装分别记录；iOS 导出/签名/真机分别记录，不将有工程等同于完成平台验证。
